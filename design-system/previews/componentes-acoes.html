Ações

Reconstruções em HTML dos componentes React Native, para documentar variantes e estados lado a lado. A fonte de verdade continua sendo o código do app.

Todo alvo tocável passa por AppPressable, que dá duas coisas de graça: estado hovered real na web (via onHoverIn/onHoverOut, inertes no nativo) e um encolher de 1 → 0,96 no toque. Componentes que não podem oscilar de tamanho passam scaleOnPress={false}.

O botão principal é a única superfície que inverte tinta e papel. É o que o torna o elemento mais pesado da tela sem precisar de cor de marca.

Três tamanhos de texto para o mesmo botão. 15px no login, 14px nas folhas de lançamento, 13px ao criar categoria — todos peso 600. Nada os distingue conceitualmente; são decisões pontuais.
